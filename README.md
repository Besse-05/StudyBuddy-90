# StudyBuddy

A web-based platform that helps students find affordable peer tutors, join study groups, share study materials, and organize study sessions in one place.

## MVP Features

1. **Find a Tutor:** browse tutors by subject, view profiles, ratings, prices, availability, and request a session
2. **Study Groups:** search groups by subject, view details, join or leave, connect with classmates
3. **Study Materials:** browse, upload, share, and search notes for exam preparation
4. **Schedule & Chat:** view upcoming sessions, schedule study sessions, chat, and receive reminders
